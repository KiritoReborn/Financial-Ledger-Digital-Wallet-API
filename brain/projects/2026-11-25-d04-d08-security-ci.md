# D04 admin security suite and D08 CI documentation validators

## Summary

- **D04 Admin Security & Tamper Detection (`tests/test_admin_security.py`)**:
  Added 20 end-to-end tests exercising invalid/missing admin credentials (`401`),
  constant-time `hmac.compare_digest` verification without short-circuiting,
  startup refusal on unset `ADMIN_TOKEN`/`ADMIN_KEY` (`FR-1.9`), rejection of
  registered non-admin user tokens on `GET /admin/reconcile` and
  `POST /transactions/{id}/reverse`, sequential and concurrent double-reversal
  race/replay behavior (`201` + `409 ALREADY_REVERSED`, `201` + `201` with
  `Idempotent-Replayed: true`), `NFR-SEC-7` error sanitization (`500`/`503`),
  and direct SQLite balance, currency, and single-sided ledger tampering
  detection via reconciliation. See [[projects/2026-11-25-d02-reversal]],
  [[2026-11-20-d03-reconciliation]], [[constant-time-secret-comparison]], and
  [[sqlite-immutability-triggers]].
- **D06 Failure-Path Coverage (`tests/test_local_check_skill.py`)**:
  Expanded validation to verify root packaging (`pip install -e ".[dev]"`,
  `python -m build`) and sanitized failure-path documentation (`503 DATABASE_BUSY`,
  `500 INTERNAL_ERROR`, cleanup, and `FAIL` summary).
- **D08 CI Skill & Brain Validators (`scripts/validate_repo_docs.py`, `.github/workflows/ci.yml`)**:
  Added a stdlib-only validator verifying YAML frontmatter and non-broken
  wikilinks across `brain/**/*.md`, matching `name`/non-empty `description`/brain
  citations/secret hygiene across `skills/*/SKILL.md`, and wired it into
  `.github/workflows/ci.yml`, backed by `tests/test_ci_validators.py`.
