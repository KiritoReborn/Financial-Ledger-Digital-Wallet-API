# D05 admin frontend page (`EI-UI-6`)

Implemented the `/admin` screen in `frontend/src/AdminPage.jsx` backed by
`frontend/src/admin.js` and `frontend/src/admin-page.css`, replacing the
`Placeholder` route in `frontend/src/main.jsx`:

- **In-memory-only credentials (`EI-UI-6`):** Prompts for the admin bearer
  token and `X-Admin-Key` (`type="password"`, `autoComplete="off"`) at session
  start and stores them strictly in React component state. Every admin request
  passes `authenticated: false` to `api()` so a signed-in user's
  `sessionStorage` token is never reused or read, and "End admin session" clears
  in-memory credentials immediately.
- **Reconciliation panel (`FR-5.1`–`FR-5.4`, `EI-UI-6`, `EI-UI-7`):** Runs
  `GET /admin/reconcile`, shows pending loading state, renders `PASS`/`FAIL`
  badges for all four invariant checks (`currencies_balanced`,
  `transactions_valid`, `wallet_balances_match`, `entry_currencies_match`), and
  displays each mismatch's check, currency/wallet/transaction IDs, and expected
  vs. actual values.
- **Confirmed idempotent reversal panel (`FR-4.2`–`FR-4.5`, `EI-UI-4`, `EI-UI-6`):**
  Validates UUID v4 transaction IDs, requires an explicit confirmation prompt
  ("Review reversal" -> "Confirm reversal") before calling
  `POST /transactions/{id}/reverse`, generates a fresh UUID v4
  `Idempotency-Key` per confirmed reversal, surfaces the `Replayed` badge when
  `Idempotent-Replayed: true`, and supports "Send again with same key" without
  automatic retries.
